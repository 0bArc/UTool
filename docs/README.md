# UTool guides

Step-by-step. Do them in order once; skip ahead when you already know a step.

| Step | Guide | You will |
|------|-------|----------|
| **01** | [Install and build](01-install-and-build.md) | Get `utool.exe` on your machine |
| **02** | [Configure your game](02-configure-game.md) | Point `utool.json` at Icarus (or another UE game) |
| **03** | [First mod](03-first-mod.md) | Build and install one pak |
| **04** | [Find assets to edit](04-find-assets.md) | Search game data, preview JSON, know what to patch |
| **05** | [Lua modding](05-lua-modding.md) | Write `mod.lua` with the DSL |
| **06** | [Build and deploy](06-build-and-deploy.md) | Pack, zip, copy to the game |
| **07** | [Multi-variant mods](07-multi-variant-mods.md) | One script → many tiers with `:Value` and `:zip` |
| **08** | [Pak Studio](08-pak-studio.md) | GUI browse, edit, build |

Examples live in [`examples/`](../examples/). Start with `morexp`, `250cap`, or `affliction_chance`.
